# Runbooks

This directory contains repeatable operational procedures for University SIS
staff and administrators. Follow each procedure's role and separation-of-duties
requirements; access is always governed by [the RBAC matrix](../RBAC_MATRIX.md).

## Procedures

| Procedure                                   | When to run                                                |
| ------------------------------------------- | ---------------------------------------------------------- |
| [Intake access review](../ACCESS_REVIEW.md) | Every intake, and after a material staffing or role change |

Store completed reviews and supporting evidence only in the institution's
approved restricted location. Do not commit names, account identifiers, or
review results to this repository.
